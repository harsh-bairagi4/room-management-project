# 🏨 Room Management Web Application

A Java-based web application developed using **JPA**, **Servlets**, and **JSP** that allows **Admins** to manage rooms (CRUD operations) and **Users** to view available rooms through a clean web interface.

---

## 📌 Project Overview

This project demonstrates a **Room Management System** where:
- **Admin** can add, update, delete, and manage room details
- **User** can view available rooms
- Data persistence is handled using **JPA (Hibernate)**
- JSP is used for frontend rendering
- The project follows **MVC architecture**

This application is ideal for learning **Java Web Development**, **JPA**, and **role-based access flow**.

---

## 🚀 Features

### 👨‍💼 Admin Module
- ➕ Add new rooms
- ✏️ Update room details
- ❌ Delete rooms
- 📋 View all rooms

### 👤 User Module
- 👀 View available rooms
- 🏨 See room details

---
## 🎯 Learning Outcomes

- Understanding **JPA & Hibernate**
- Working with **Servlets & JSP**
- Implementing **CRUD operations**
- Role-based module separation (Admin & User)
- Applying **MVC architecture** in real projects
